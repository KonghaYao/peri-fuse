## 2. 数据收益明细

### 2.1 迁移后构成（审计①严格口径）

| 组成 | 字节 |
|---|---|
| 转换行 manifest 存储（`input` 列） | 139,633,634 |
| 非候选行存储（不变） | 156,644,661 |
| 内容池（`io_cas_chunks`，20,082 块） | 31,275,847 |
| **合计** | **327,554,142** |

- 转换行合计 = 139,633,634 + 31,275,847 = 170,909,481 B（原 1,497,872,337 B，**-88.6%**）
- 池压缩：池原始内容 73,472,205 B → 存储 31,275,847 B（**-57.4%**，manifest 74 B 头 + body，仅更小才 deflate）
- REF 去重：324,213 个引用 → 20,082 唯一块（**-93.8%**，块数口径；字节口径 1,146,063,926 B 引用原文 → 73,472,205 B 唯一内容，-93.6%）

### 2.2 对照口径

| 方案 | 存储 | 相对原文 |
|---|---|---|
| 原文（迁移前） | 1,654,516,998 | 100% |
| 全量 codec1（deflate）基线 | 535,126,144 | 32.3% |
| **CAS（实测）** | **327,554,142** | **19.80%** |
| 回退后（codec1，expand 实测） | 634,231,889（input 列） | 38.3% |

CAS 相比「全量 codec1 压缩」再省 **38.8%**——去重收益无法由单行压缩获得。

### 2.3 dry-run 预测 vs 实测

- dry-run 预测存储 395,787,753 B（保守上界：manifest 按未压缩预算），实测 327,554,142 B，**实测比预测低 17.2%**（manifest 实际压缩后 139,633,634 B，低于预测）。
- **2000 行抽样外推严重失真**（uniqueChunks 外推 180,537 vs 实际 20,082），全量 dry-run 才准确——迁移前评估必须全量。

## 4. 执行开销（单项目 49,435 行 / 1.65 GB 原文）

| 作业 | 耗时 | 吞吐 | lockWait P95 | business P95 |
|---|---|---|---|---|
| backfill-v1 | 88.2 s | 18.8 MB/s | 0.037 ms | 0.082 ms |
| expand-v1（回退） | 85.4 s | 17.5 MB/s | 0.165 ms | 0.264 ms |
| backfill-v1 pass 2 | 67.0 s | 24.7 MB/s | 0.037 ms | 0.090 ms |

- 批大小 ≤32 行或 8 MiB；IMMEDIATE 事务内逐行快照比对；WAL 全程 0.8–3.8 MB。
- 锁等待与业务处理 P95 均远低于毫秒级阈值，对并发写入的干扰窗口极小。

冒烟发现并修复一个**真实产品缺陷**：快照 SQL 断言把 traces 合法列名 `release` 误判为 `RELEASE SAVEPOINT` 控制语句，导致所有选取 `release` 列的读快照端点 500（`SQLITE_READONLY`）。修复按语句位置判定（首 token + 单语句 + WITH 顶层写关键字 + `load_extension`），commit `3fc8cd9`，含回归测试。

## 6. 边界与限制（如实声明）

1. 副本是**静态快照**：迁移期真实并发写入 / 中断续跑未在真实库重复，由 W7 合成语料 + 并发 + SIGKILL 测试覆盖；写路径（迁移期间并发摄入）未在真实库验证。
2. 非候选小行（44,856 行 / 156.6 MB 原文）按设计保持不压缩——这是 -80.2% 与「转换行 -88.6%」差距的主要来源。
3. SDK 端到端（真实 Langfuse SDK 写入）未跑；HTTP 层为单机验证。
4. DB 文件体积不随迁移下降（不 VACUUM）；释放的 319,143 空闲页供后续写入复用。

## 7. 结论

在 1.65 GB / 49,435 行的真实数据上，CAS 迁移将 input 存储降至 **19.80%**（转换行 **11.41%**），全部审计口径 0 mismatch，回退与二次迁移幂等。**可以完美迁移**；正式迁移建议在停机窗口内执行 backfill → 审计 → 切换（回退载体 expand 已在真实数据验证）。
